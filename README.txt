Usagi lang / .yaha / C++17 / UTF-8 with BOM

기존 main.cpp를 교체하세요. keywords.lang과 example.yaha도 함께 교체합니다.
Visual Studio: C++17, 콘솔(/SUBSYSTEM:CONSOLE), /utf-8 사용.
별도 Support.cpp / Language.cpp 등은 이 단일 main.cpp 빌드에 포함하지 마세요.

Developer Command Prompt 빌드:
cl /std:c++17 /EHsc /utf-8 main.cpp /Fe:Usagi-lang.exe

파일 실행:
Usagi-lang.exe example.yaha
Usagi-lang.exe --lang keywords.lang example.yaha
결과: 21

인자 없이 실행:
Usagi-lang.exe
여러 줄 코드를 입력한 뒤 빈 줄로 실행합니다. :exit로 종료합니다.
빈 줄마다 독립 실행하므로 함수 선언과 그 호출은 같은 입력 묶음에 넣으세요.

수정된 함수 규칙:
하앗! 하아! 우라 ... 하아? : 함수 1 선언, 우라는 매개변수
하아- 식 : 함수 1을 호출하고 식의 값을 인자로 전달
하아아! / 하아아- / 하아아? : 함수 2 선언 / 호출 / 종료
아의 개수가 함수 번호입니다.
함수 선언 뒤에 나열한 변수의 개수만큼 호출 인자를 읽습니다.
각 인자는 숫자뿐 아니라 산술식, 함수 호출 등 완전한 표현식입니다.
하아- 뒤에서 함수 이름을 찾거나, 호출 대신 숫자만 반환하는 동작은 제거했습니다.
재귀/전방 호출을 지원하고 호출마다 지역 변수를 따로 보관합니다.
정의하지 않은 함수, 인자 누락, 선언/종료 번호 불일치는 오류입니다.

조건문:
푸루 / 푸루루 / 푸루루루 : if == / if < / if >
푸루 푸루루 A B : A == B 또는 A < B
연속 비교어는 같은 두 피연산자를 공유합니다.
본문 하나 또는 하! ... 하? 블록을 사용합니다.

표현식:
푸릿 A B : A+B
푸리릿 A B : A-B
푸리리릿 A B : A*B
푸리리리릿 A B : A/B
푸루야 식 : 반환
미야아야하 식 : 출력
우라 ? 식 : 변수 대입
이야하!!! : -3 / 이이야하!!! : 3 / 야하 : 0

example.yaha는 수정된 조건문 문법을 사용하는 피보나치 예제입니다.
기존 '푸루루 야하!!! 하! 푸릿 야하! 하?' 형태는 비교 대상과 반환 명령이
맞지 않으므로 함께 제공한 예제를 사용하세요.

Linux g++에서 피보나치 21과 14개 함수/인자/지역변수/조건/콘솔 검증을 통과했습니다.
Windows 실행 자체는 이 환경에서 검증하지 않았습니다.
