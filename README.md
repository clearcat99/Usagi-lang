# Usagi-language

치이카와의 우사기처럼 귀엽게 코딩하고 싶으신 여러분을 위한 프로그래밍 언어입니다. 부디 우라-야하! 하시길 바랍니다.

## 문법 (Syntax)

기본적으로 **Prefix 형식**입니다. `함수 인자1 인자2...` 형태로 구현되어 있습니다.

정수에 대한 함수, 변수, 출력이 가능합니다.

### 1. 정수 (Integer)

`야하`에 표현하려는 숫자만큼 느낌표(`!`)를 사용합니다.

```text
야하!!!         // 3
```

`야하` 앞에는 `이`가 올 수 있습니다. 하나 붙일 때마다 부호가 바뀝니다.

```text
이야하!!!       // -3
이이야하!!!     // 3
이이이야하!!!   // -3
```

### 2. 변수 (Variable)

`우`로 시작하며 `우`, `라`, `아`가 포함된 단어로 변수를 선언하고 사용할 수 있습니다.

변수는 오직 **글자의 수**로만 구분됩니다. `우라아`와 `우우라`는 같은 변수입니다. (우사기처럼 자유롭게 변주해보세요)

변수에 값을 대입하기 위해서는 `미야아아`를 써주세요.

```text
미야아아 우라 야하
```

위 코드는 `우라 = 0`을 의미합니다.

### 3. 사칙연산 (Arithmetic Operators)

연산자는 `푸릿`의 변형입니다. 현재 연산자에 할당된 단어는 다음과 같습니다.

| 연산자 | 기능 | 기호 |
|---|---|---|
| `푸릿` | 덧셈 | `+` |
| `푸리릿` | 뺄셈 | `-` |
| `푸리리릿` | 곱셈 | `*` |
| `푸리리리릿` | 나눗셈 | `/` |

### 4. 출력 (Print)

`미이이야하`를 사용합니다. `미이이야하` 뒤에 출력할 정수나 표현식을 사용할 수 있습니다.

**정수 출력**

```text
미이이야하 야하!!
```

출력 결과:
```text
2
```

**표현식 출력**

```text
미이이야하 푸릿 야하!! 야하!!!
```

출력 결과:
```text
5
```

### 5. 함수 (Function)

함수의 정의는 `우라-야하!`로 시작합니다.

함수는 `하아`의 변형입니다. 뒤에 오는 `아`의 개수로 구분됩니다.

함수는 `!`로 시작하고 `?`로 끝납니다. `하아아` 함수는 `하아아!`로 시작하고 `하아아?`로 끝납니다.

**함수 정의**

함수 시작 시 변수를 나열해서 파라미터를 표현할 수 있습니다.

```text
우라-야하! 하아! 우라 우라라
```

**함수 호출**

함수를 호출할 때는 `-`를 사용합니다.

`하아아` 함수의 호출은 `하아아-`입니다.

### 6. 조건문 (Conditional Statements)

조건문은 `푸루`의 변형입니다.

| 조건문 | 기능 |
|---|---|
| `푸루 A B` | `if A == B` |
| `푸루루 A B` | `if A < B` |
| `푸루루루 A B` | `if A > B` |

편의상 두 개의 조건문 키워드를 붙여 쓸 경우 `or`로 동작합니다.

```text
푸루 푸루루     // if <=
```

기본적으로 조건문 뒤의 문장 하나를 실행하는데, 만약 두 개 이상의 문장을 실행해야 할 경우 `하!`와 `하?`로 범위를 표시해줘야 합니다.

```text
푸루루 우라 야하 하! (실행할 내용) 하?
```

## 예시 (Examples)

일반적인 코드를 Usagi-lang으로 번역한 예시입니다.

### Fibonacci

**일반적인 코드**

```c
int fibonacci(int num)
{
    if (num < 3)
    {
        return 1;
    }
    else if (num >= 3)
    {
        return fibonacci(num - 1) + fibonacci(num - 2);
    }
}

print(fibonacci(8));
```

**Usagi-language**

```text
우라-야하! 하아! 우라
푸루루 우라 야하!!! 하! 푸루야 야하! 하?
푸루 푸루루루 우라 야하!!! 하! 푸루야 푸릿 하아- 푸리릿 우라 야하! 하아- 푸리릿 우라 야하!! 하?
하아?

미이이야하 하아- 이이이이야하!!!!!!!!
```

## 실행 방법 (How to use)

인터프리터 언어입니다. Usagi-lang.exe를 실행하시거나 main.cpp를 빌드해서 사용하실 수 있습니다.

실행 인자로 .yaha 파일을 넣어 미리 작성된 .yaha를 실행 시키실 수 있습니다.

.lang 파일 수정 후 실행 인자 --lang으로 .lang파일을 넣어 키워드를 변경하실 수 있습니다. '우라'보다 '우나' 취향이신 분들, '푸릿' 대신 '쁘륏'을 사용하고 싶으신 분들은 변경해서 사용해주시면 됩니다.
